# Transub

**智能化字幕生成工具 & 字幕优化编辑**

批量生成 · 精修成片 · Windows 桌面  
当前版本 **3.0.5** · [下载](https://github.com/dlsandy/Transub/releases) · [变更记录](CHANGELOG.md) · [爱发电 / Pro](https://afdian.com/a/transub)

包含：Transub字幕生成器、Transub Editor字幕编辑器、Transub Engine引擎

---

## 适合谁？

- 整批视频快速出 SRT / VTT / ASS
- 把字幕初稿改到能上片：控读速、清杂音、统一专名、语句润色
- 多语种 / 混批素材，拖进去就能开跑
- 需要无人值守：开跑后可睡眠 / 退出 / 关机

## 核心能力

### 拖进音视频，批量开跑

批量生成

添加文件或文件夹 → 选转写 / 翻译 / 双语 → 开始。进度与日志一目了然；完成后可一键快速修复质量或进编辑器实时编辑预览。

- 自动感知语种、音视频类型与切分策略
- 支持GPU 加速；任务结束可选睡眠 / 关机

### 生成后自动优化

自动优化、修复字幕质量

任务结束后自动质检、拆句、清杂音与叠词压缩；列表直接看到问题数。

### 结构化字幕编辑器

字幕编辑器

列表、详情、预览联动；按置信度、质检、审校、说话人、书签筛选。可独立启动 **Transub Editor**。

### 质量检查 + 一键修复

质量检查

扫描重叠、读速、时长、通顺度等；时间类问题可预览后一键修。双语还可查空译、漏译、术语缺失。

Pro版本支持质疑问题进行深入修复

### 智能分割与时长

分割与时长

读速提示、智能断句、静音分割、智能时长；快捷键对齐播放头。

### 视频预览 + 波形时间轴

时间轴与波形

边播边改；可选波形与磁吸拖拽；局部重转写、书签与 A-B 循环。

## 三种译中方式


|        | 机器翻译（Opus） | 推理翻译    | 智能翻译（Pro） |
| ------ | ---------- | ------- | --------- |
| **许可** | 免费         | 免费      | 需本大版本 Pro |
| **质量** | 赶工够用       | 口语更自然   | 专名与上下文最稳  |
| **适合** | 大批量、要速度    | 质量与速度折中 | 成片级一致性    |


> 翻译质量跟选择合适的模型有很大的关系，例如日译中 推荐使用推理翻译的sakura 1.5B或7B模型，智能翻译推荐使用Qwen2.5 1.5B或7B模型。

## 下载安装

1. 打开 [Releases](https://github.com/dlsandy/Transub/releases)，下载 **软件zip压缩包**
2. 解压后运行 `Transub.exe`（目录内有编辑器快捷方式）
3. **首次请走设置向导**，按硬件勾选并下载模型 / 运行库（体积较大，请耐心等待）
4. 之后用应用内「检查更新」升级即可；已装模型与运行库会保留

>


| 要求              | 说明                         |
| --------------- | -------------------------- |
| Windows 10 / 11 | 唯一支持平台                     |
| 其它              | 引擎与 FFmpeg 已内置，无需本机 Python |


> 当前发行包未做代码签名。可选注册右键菜单：`tools/register-context-menu.ps1`

## 从源码运行

需要 **Node.js ≥ 22.12**。

```bash
git clone https://github.com/dlsandy/Transub.git
cd Transub
npm install
npm run setup:ffmpeg
# 将 Engine 独立版放到 transub-engine/（含 runtime\python.exe）
npm start
```

打包：`npm run dist` 或 `build-win.bat`。更多脚本与结构见仓库 `tools/`、`docs/`。
