    问题报告

    尚未对照
    怎么训练与修改（点此展开）
    1. 选片子 → 对照：左侧点番号，看「待修」数字。待修为 0 就不用训。
    2. 只盯真问题：保持「只看待修」。彩色标签（如「イク误成射」）才值得改；「对齐可疑」「已修好」一般别写规则。
    3. 勾一条 → 填短片段：右侧填日文锚点与 `错误片段→改成`。整句预览只用于试跑，不以整句入库。
    4. 先试跑再写入：试跑通过后再点「写入并验证」。写入后建议点「跑全部测试」防回归。
    5. 懒人方式：点「生成规则草案」→ 默认只勾短片段、低误伤项 → 写入。整句润色勿写。
    6. 批量抽片段：勾选若干句 →「抽规则片段」→ 弹窗确认短 `zhFrom→zhTo` 后再写入。
    7. 改错了怎么办：点「已学规则」→ 停用 / 删除；或用同一锚点重新写入覆盖。

    别写规则的情况：日文是 &、乱码、对不上的长中文（对齐坏了，去改字幕文件）；拟声被洗成「…」通常是对的；「规则已改好的样例」只是成功演示，不是待办。

    三种类型：「改中文」= 译文错了；「听写纠错」= 日文听写错了；「清空弱化」= 整句变成「…」（很少用）。

    规则已改好的样例 0 （成功示例，一般不用再训）

    这里是清洗规则已经改动过的句子：改前→改后。拟声变「…」、错译被纠正，都算正常。只有你觉得「改后更糟」时，才到右侧针对那句重新训练。
